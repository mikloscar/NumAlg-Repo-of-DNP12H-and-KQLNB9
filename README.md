# NumAlg-Repo-of-DNP12H-and-KQLNB9

This is the readme file for the NumAlg project of DNP12H (Bugyi Vivien Kincső) KQLNB9 (Márk Czura)
We have chosen to simulate brownian motion with visuals. Our goal is to examine how the distance of the walk changes over time, and analyze the resulting probability distributions.
